Cloud Build pricing
Cloud Build charges for build-minutes consumed. A build-minute is incurred every minute that a build is in process. Partial minutes are billed at the actual number of seconds consumed. Network egress will be charged according to standard rates.
Each billing account comes with 2,500 free build-minutes per month.1
Build-minutes are not incurred for the time that a build is queued. Charges are accrued to the billing account associated with the Google Cloud console project that initiated the build.
