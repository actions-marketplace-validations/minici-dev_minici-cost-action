MiniCI — 1-Click GitHub App & Slack PR Bot Setup

Runs on https://api.minici.dev (the Worker route in wrangler.jsonc). Self-hosting? Change MINICI_API_URL below and in the manifest.

1. Register MiniCI GitHub App in 1 Click

Creates a GitHub App pre-wired to /webhooks/github with least-privilege permissions (pull_requests: write, issues: write, checks: write, contents: read, actions: read).


After GitHub creates the App, save its Webhook Secret & Installation Token in Cloudflare:
npx wrangler secret put GITHUB_WEBHOOK_SECRET & npx wrangler secret put GITHUB_APP_TOKEN

2. Create Slack PR Bot & Incoming Webhook (60 Seconds)

  1. Open https://api.slack.com/apps?new_app=1 → From an app manifest.
  2. Paste integrations/slack-app-manifest.json → click Create → Install to Workspace.
  3. Copy your Webhook URL (https://hooks.slack.com/services/...) and Signing Secret:
# Test Slack PR Cost / Breakdown Card locally right now:
minici comment slack --path . --webhook-url "https://hooks.slack.com/services/..." --consent

# Enable Interactive Slack Buttons on Cloudflare Worker:
npx wrangler secret put SLACK_SIGNING_SECRET
